# Husein's Web Portfolio

This website serves as a personal portfolio to showcase my web development projects.  
It also highlights my skills and competencies as a **Junior Web Developer**, making it easier for visitors and recruiters to understand my technical background.

---

## Tech Stack
- React
- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Bun

---

## Local Development

```bash
bun install
bun run dev
```

Build dan jalankan versi production:

```bash
bun run build
bun run start
```
